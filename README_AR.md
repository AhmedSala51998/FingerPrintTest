# مشروع تسجيل الدخول بالبصمة - PHP + MySQL

هذا المشروع يستخدم WebAuthn/Passkey. البصمة نفسها لا يتم إرسالها أو تخزينها في قاعدة البيانات؛ الهاتف/المتصفح يقوم بالتحقق البيومتري ويوقع طلبًا، والخادم يتحقق من التوقيع.

## المتطلبات

- PHP 8.0 أو أحدث.
- MySQL/MariaDB.
- HTTPS على الدومين.
- Composer لتثبيت مكتبة `lbuchs/webauthn`.
- متصفح يدعم WebAuthn/Passkeys.
- OpenSSL و mbstring، ويفضل Sodium.

المكتبة المستخدمة مثبتة على الإصدار 2.2.0.

## 1) قاعدة البيانات

افتح phpMyAdmin واستورد:

`database.sql`

ثم عدّل بيانات قاعدة البيانات في:

`config.php`

مثال:

DB_NAME = اسم قاعدة البيانات
DB_USER = مستخدم قاعدة البيانات
DB_PASS = كلمة المرور

## 2) تثبيت المكتبة

إذا كان عندك Terminal/SSH/Composer:

```bash
composer install --no-dev
```

سيتم إنشاء مجلد `vendor`.

إذا كانت الاستضافة لا توفر Composer، نفّذ الأمر على جهازك ثم ارفع المشروع كاملًا بما فيه مجلد `vendor`.

## 3) الدومين

إذا كان موقعك:

https://example.com

يمكن ترك:

```php
const RP_ID = '';
```

وسيتم اكتشاف الدومين تلقائيًا.

أو اكتب:

```php
const RP_ID = 'example.com';
```

مهم: لا تكتب `https://` داخل RP_ID.

## 4) طريقة الاستخدام

افتح:

`https://example.com/register.php`

اكتب اسم الشخص واضغط "تسجيل البصمة".

سيطلب الهاتف بصمة الإصبع/Face ID/رمز قفل الجهاز.

بعد التسجيل، افتح:

`https://example.com/`

واضغط "تسجيل الدخول بالبصمة".

سيختار الهاتف الـ Passkey الخاص بالموقع ويتحقق من المستخدم.

بعد النجاح ينتقل إلى:

`welcome.php`

ويظهر:

"مرحبًا، اسم الشخص"

## ملاحظة مهمة

هذه ليست بصمة يتم تخزينها كصورة أو رقم بصمة في MySQL. WebAuthn مصمم بحيث لا تصل البصمة الحيوية نفسها إلى الموقع. الذي يتم تخزينه هو بيانات الاعتماد العامة اللازمة للتحقق من التوقيع.

## إذا ظهر خطأ

أكثر سببين شائعين:

1. الموقع ليس HTTPS.
2. الدومين في RP_ID لا يطابق الدومين الذي تفتح منه الموقع.

للاختبار على الهاتف، استخدم الدومين الحقيقي مع SSL وليس رابط HTTP.
